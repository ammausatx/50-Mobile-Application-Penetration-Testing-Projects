# Contributing

- Keep every exercise within an owned, intentionally vulnerable lab or written scope.
- Use synthetic accounts, data, and test devices.
- Record app version, APK SHA-256, Android API level, tool versions, and timestamps.
- Separate observations from confirmed findings; include false-positive checks and limitations.
- Never commit credentials, tokens, private keys, personal data, proprietary APKs, or unredacted customer evidence.
- Label all simulated screenshots and sample output. Never represent illustrations as genuine tool output.
- Include remediation and repeatable retest criteria in every project.
